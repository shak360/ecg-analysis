Local corpus

For learning. Every tracing is a real, de-identified ECG, and every label is the original cardiologist's, not this tool's. Sources are PTB-XL (Wagner et al. 2020) and the PhysioNet/CinC Challenge 2021 set — Chapman-Shaoxing, Ningbo, Georgia, CPSC, INCART and PTB — all CC BY 4.0 via PhysioNet. Label review differs by source, and each case says which it is: PTB-XL records whether a human validated the label and only those are taken, while the others are shown as published. Findings are shown as recorded; this page does not interpret.
